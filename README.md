# 🌍 EnviroScan - Anomaly Detection using DBSCAN

This project detects unusual environmental patterns using DBSCAN clustering on air quality data, helping identify abnormal pollution conditions.

---

## ⚡ Features

* **Density-Based Detection:** Uses DBSCAN to identify clusters and noise points (anomalies)
* **Automatic Outlier Detection:** No need to predefine number of clusters
* **Data Visualization:** Graphical representation of clusters and anomalies
* **Real-world Dataset:** Applied on air quality data (PM2.5, NO₂, etc.)

---

## ⚙️ Setup

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the notebook:

```bash
jupyter notebook
```

---

## 📊 Dataset

This project uses an air quality dataset with parameters such as PM2.5, PM10, NO₂, SO₂, CO, and O₃.

📁 File:

* `pollution_data.csv`

⚠️ Ensure the dataset file is available in the correct path before running the notebook.
